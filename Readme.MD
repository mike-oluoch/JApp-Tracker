# Job Application Tracker

A simple, lightweight job application tracker built with **HTML**, **CSS**, and **JavaScript**. This application allows you to manage your job applications directly in your browser, with data stored locally using `localStorage`.

---

## Features

- **Add Applications**: Add details such as company, job title, location, date applied, status, and notes.
- **Edit Applications**: Modify existing job applications.
- **Delete Applications**: Remove applications with a confirmation prompt.
- **Search**: Search applications by company, job title, or location.
- **Dashboard Statistics**: View total applications, applied, interviews, and offers.
- **Status Indicators**:
  - Applied
  - Interview
  - Offer
  - Rejected
- **Responsive Design**: Works on both desktop and mobile devices.
- **Data Persistence**: All data is stored in `localStorage` and persists across browser sessions. No login required.
